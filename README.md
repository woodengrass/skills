# 個人用 Skills

這個倉庫收錄我自用的 coding agent 技能和工作指引。

- [`AGENTS.md`](./AGENTS.md)：工作指引，涵蓋工作範圍、驗證方式與決策紀錄。
- [`skill/adr/SKILL.md`](./skill/adr/SKILL.md)：`adr` 技能，用 `GOALS.md` 記錄專案目標，並在相關程式碼旁用 `*.adr.md` 記下長期決策。
- [`skill/tests-that-catch-bugs/SKILL.md`](./skill/tests-that-catch-bugs/SKILL.md)：撰寫測試時，驗證受保護的行為一旦出錯，測試就會失敗。

## 安裝

把下面的 prompt 貼給你正在使用的 coding agent：

```text
請讀取 https://raw.githubusercontent.com/woodengrass/skill/main/INSTALL.md 並依照指引幫我安裝。
```
